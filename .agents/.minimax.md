# Graphify TypeScript Port - Progress Report

## Project Goal
Port Python graphify codebase to TypeScript as a Node.js library + CLI tool that extracts code structure, builds graphs, and generates HTML visualizations.

## Constraints & Preferences
- Local clone and use model (no npm publishing)
- Pre-extraction model for Vercel deployment (graph built once, served statically)
- dist/ folder gitignored (users build locally)
- User triggers graphify manually from a button in their app
- Using graphlib instead of NetworkX for JS

### Core Files Implemented

1. **Types** (`src/types/index.ts`)
   - GraphNode, GraphEdge, FileType, Confidence types
   - Communities, AnalysisResult, GodNode, SurprisingConnection
   - LanguageConfig, VALID_FILE_TYPES, VALID_CONFIDENCES

2. **Detection** (`src/detect/`)
   - `file-type.ts` - File classification by extension
   - `ignore.ts` - .graphifyignore handling
   - `index.ts` - Directory scanning with filtering

3. **Extraction** (`src/extract/`)
   - `utils.ts` - ID generation (nodeId, edgeId)
   - `languages/types.ts` - Language configs
   - `index.ts` - Main extraction logic (regex-based)

4. **Graph Building** (`src/build/`)
   - `validate.ts` - Schema validation
   - `dedup.ts` - Node deduplication by label
   - `index.ts` - Graph construction from extractions

5. **Clustering** (`src/cluster/`)
   - `cohesion.ts` - Community cohesion scoring
   - `index.ts` - Louvain-like community detection

6. **Analysis** (`src/analyze/`)
   - `god-nodes.ts` - Most connected entities detection
   - `surprising.ts` - Cross-community connections
   - `index.ts` - Full analysis + graph diff

7. **Export** (`src/export/`)
   - `json.ts` - JSON export with normalized labels
   - `html.ts` - vis.js HTML visualization
   - `index.ts` - Export module

8. **Query** (`src/query/`)
   - `scoring.ts` - TF-IDF based node scoring
   - `search.ts` - BFS/DFS search
   - `index.ts` - Path finding, explain functionality

9. **Utilities** (`src/utils/graphlib.ts`)
   - `graphNodes()` - Get all nodes as array
   - `graphDegree()` - Get single node degree
   - `graphDegrees()` - Get all node degrees
   - `graphNeighbors()` - Get node neighbors
   - `graphEdges()` - Get all edges as array
   - `setDifference()` - Set subtraction

10. **Main API** (`src/index.ts`)
    - Graphify class with build(), toJSON(), toHTML() methods
    - Full export of all modules

11. **CLI** (`bin/graphify.js`)
    - Commands: build, query, path, explain, export
    - Options: --input, --output, --format, --viz

## Graphlib API Compatibility Fixes

The main challenge was that graphlib's API differs from Python's NetworkX. Key fixes applied:

1. Created helper utilities in `src/utils/graphlib.ts`:
   - Replaced `G.nodes()` → `graphNodes(G)` (graphlib returns GraphNode objects, not strings)
   - Replaced `G.edges()` → `graphEdges(G)` (returns different format)
   - Replaced `G.degree(node)` → `graphDegree(G, node)`
   - Replaced `G.degree()` → `graphDegrees(G)`
   - Replaced `G.neighbors()` → `graphNeighbors(G, node)`
   - Replaced `G.subgraph()` - manually built subgraph
   - Replaced `Set.subtract()` → `setDifference()`

2. Updated all files to use these helpers:
   - `analyze/god-nodes.ts`
   - `analyze/surprising.ts`
   - `analyze/index.ts`
   - `cluster/index.ts`
   - `cluster/cohesion.ts`
   - `query/scoring.ts`
   - `query/index.ts`
   - `build/index.ts`
   - `export/html.ts`
   - `export/json.ts`
